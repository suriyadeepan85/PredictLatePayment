# PredictLatePayment

Hackathon prototype: predict which invoices will be paid late, so receivables teams can act before the due date instead of chasing after it.

Start here:
- `STATUS.md`: where the project is and what's waiting for approval
- `DECISIONS.md` and `OPEN_ITEMS.md`: decisions, observations, questions, assumptions
- `docs/data_contract.md`: the data contract
- `specs/methodology.md`: how decisions become specs

Data is not in this repo. Download `dataset.csv` from Kaggle (`pradumn203/payment-date-prediction-for-invoices-dataset`) into `data/raw/customer_invoices.csv` and check its SHA-256 against `docs/data_contract.md`.
